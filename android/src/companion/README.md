# BosonQuiche Android companion

This artifact supplies the Android ARM64 JNI library for BosonQuiche
${project.version}. Java classes and full JavaDoc are supplied by its
transitive API dependency:

`io.bosonnetwork:boson-quiche:${project.version}`

See `boson-quiche-${project.version}-sources.jar` and
`boson-quiche-${project.version}-javadoc.jar` for the Java API sources and
documentation. This source companion includes the Android manifest, JNI keep
rules and shared native implementation.

Project: https://github.com/bosonnetwork/BosonQuiche
